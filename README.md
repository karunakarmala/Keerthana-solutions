# Keerthana Solutions — Frontend

Responsive React + Vite frontend for **KEERTHANA SOLUTIONS — By Katakam Venkatesh**.

## Included
- Premium responsive homepage
- Sticky navigation + mobile menu
- Hero section with approved construction visual direction
- Trusted businesses bar with OLA and more+
- Services: Commercial Construction, Branch / Outlet Setup, Office Construction, Interior & Civil Works
- How It Works process
- OLA Hyderabad project showcase
- Uday testimonial
- Project/contact CTA
- Project request modal/form (frontend only)

## Run locally
```bash
npm install
npm run dev
```

Then open the Vite URL shown in the terminal.
